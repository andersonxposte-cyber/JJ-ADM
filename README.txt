JJ ADM — PROTÓTIPO FUNCIONAL

Conteúdo:
- index.html: aplicação web responsiva.
- Dados guardados localmente no navegador através de localStorage.
- Campeonatos Contra Squad e Mapa Aberto.
- Registo de equipas, sorteios simples, resultados de quedas e estado.
- Inventário de notas.
- Estatísticas e exportação/importação de backup JSON.

COMO TESTAR:
1. Extrai o ZIP.
2. Abre index.html num navegador moderno.

IMPORTANTE:
Este pacote NÃO é um APK compilado. É um protótipo funcional de interface e lógica local.
Não inclui ainda sincronização real na nuvem, autenticação, upload de fotografias nem compilação Android/iOS.
Para gerar APK, é necessário integrar o projeto numa estrutura Android (por exemplo, Capacitor/Android Studio) e compilar com Android SDK.
Para iPhone é necessária compilação iOS num ambiente macOS com Xcode.
